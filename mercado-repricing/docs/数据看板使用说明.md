# 数据看板

0.5.27 起首页提供所选 Meli 店铺的 UpSeller 销售数据。午夜流光为默认外观，其余皮肤仍可在皮肤中心切换。日常调价、周末报名、记录与标签功能保留。

## 数据连接

默认读取当前 Windows 用户桌面的“每日消息推送”文件夹。其他位置可在“连接设置 → UpSeller 数据看板”填写。该文件夹需有现有每日推送工具的 config.json、有效 UpSeller 登录文件以及配置中引用的分类表、利润工作簿。无需运行每日推送或发送消息。

- 店铺、月目标、BRL/CNY 汇率取自 config.json 的 shops、target_cny 与 brl_to_cny；店铺必须有精确 upseller_name。
- 登录文件使用现有工具的 .upseller_cookie 或 .upseller_cookie.txt。仅服务端读取，网页不会取得凭据。
- 分类取 sku_classification_file 指向工作簿的 SKU、产品定义列，支持 A/B/KA/P，其他显示未分类。
- 毛利取 profit_workbook_file 中“利润表-Meli”的 C 列 SKU、AB 列已保存毛利率。只读缓存值，不重算或改写原工作簿。
- 同事电脑需使用自己的有效配置和权限。程序安装包不携带本机登录文件、报表或经营数据。

## 统计与交互

按每日推送的上海日历显示昨日、近七个完整自然日及统计月累计，所有累计均截至昨日，不混入今日未结束数据。月初显示上一统计月的完整月数据。数据由 UpSeller 统计接口返回，不代表逐秒订单流；每5分钟自动读取，顶部可手动强制刷新。界面标明更新时间。历史有效销售额、订单和毛利可能随后续接口/利润表更新而变化，不保证等于早先发送的静态日报图片；同一时点同一口径才能对账。

有效销售额与有效订单沿用 list-shop 口径；SKU 类目与排行沿用 variation-sale-all-list 口径。两种报表合计可能不同，分别显示，不按比例摊平。SKU 订单量不能加总替代店铺订单量。

毛利金额按 SKU 平均售价 × 有效产品销量 × 已保存毛利率估算，再除以店铺有效销售额得到预估毛利率。不是平台结算净利润；缺失或冲突时显示“—”与数据提示，不用 0 替代。

月目标换算为 BRL，目标差额最低为0；剩余日均按报告日之后到该统计月底计算，包括今日，但不重复计入已经结束的报告日。统计月已结束时日均显示“—”。无目标时完成率、差额、剩余日均显示“—”。前一日销售额为0时涨幅显示“—”。

环形图、折线、目标进度与排行条形有入场动画，并尊重系统“减少动态效果”。鼠标或键盘可查看趋势节点、类目；排行可搜索 SKU/产品名称、展开完整列表。小屏保留可横向滚动的完整明细表。

## 异常

网络或登录失效时显示错误并可重新读取，不用其他店铺或过期预览数据填充。更新登录状态须在原每日推送工具完成。切换店铺会取消上次读取；服务端再次核对精确店铺、ID、BRL 币种与分页完整性。

看板不调用任何改价、报名、退出活动或发送消息接口，也不启动或恢复调价任务。
