# 数据看板

0.5.27 起首页提供所选 Meli 店铺的 UpSeller 销售数据。午夜流光为默认外观，其余皮肤仍可在皮肤中心切换。日常调价、周末报名、记录与标签功能保留。

## 数据连接

本机同事压缩包默认使用包内“每日消息推送”目录，无需同事另找配置或补填凭据；也可在“连接设置 → UpSeller 数据看板”切换到本机其他目录。压缩包内只保留 Meli 店铺看板所需配置、UpSeller 登录文件、分类表和利润工作簿，不包含每日推送日志、Webhook、浏览器配置或其他频道配置。包内登录凭据由本地服务读取，请仅发给有权限的同事。无需运行每日推送或发送消息。

- 店铺、月目标、BRL/CNY 汇率取自 config.json 的 shops、target_cny 与 brl_to_cny；店铺必须有精确 upseller_name。
- 登录文件使用现有工具的 .upseller_cookie 或 .upseller_cookie.txt。仅服务端读取，网页不会取得凭据。本机同事压缩包会携带该登录文件和看板必需的两张工作簿；GitHub 源码快照不携带这些本机文件。
- 分类取 sku_classification_file 指向工作簿的 SKU、产品定义列，支持 A/B/KA/P，其他显示未分类。
- 毛利取 profit_workbook_file 中“利润表-Meli”的 C 列 SKU、AB 列已保存毛利率。只读缓存值，不重算或改写原工作簿。
- SKU 批次对应表由本机同事压缩包内置，放在程序目录的“批次对应表.xlsx”，设置页只读显示匹配数量，不提供上传入口。公开 GitHub 源码不包含该运营表。

## 统计与交互

按每日推送的上海日历显示昨日、近七个完整自然日及统计月累计，所有累计均截至昨日，不混入今日未结束数据。月初显示上一统计月的完整月数据。数据由 UpSeller 统计接口返回，不代表逐秒订单流；首次查看店铺读取一次；页面切换及返回已查看店铺复用本次会话的快照，不定时自动读取。点击顶部刷新才强制重新获取；重开网页或更换数据源重新读取。界面标明更新时间。历史有效销售额、订单和毛利可能随后续接口/利润表更新而变化，不保证等于早先发送的静态日报图片；同一时点同一口径才能对账。

有效销售额与有效订单沿用 list-shop 口径；SKU 类目与排行沿用 variation-sale-all-list 口径。两种报表合计可能不同，分别显示，不按比例摊平。SKU 订单量不能加总替代店铺订单量。

毛利金额按 SKU 平均售价 × 有效产品销量 × 已保存毛利率估算，再除以店铺有效销售额得到预估毛利率。不是平台结算净利润；缺失或冲突时显示“—”与数据提示，不用 0 替代。

月目标换算为 BRL，目标差额最低为0；剩余日均按报告日之后到该统计月底计算，包括今日，但不重复计入已经结束的报告日。统计月已结束时日均显示“—”。无目标时完成率、差额、剩余日均显示“—”。前一日销售额为0时涨幅显示“—”。

环形图、折线、目标进度与排行条形有入场动画，并尊重系统“减少动态效果”。鼠标或键盘可查看趋势节点、类目；排行可搜索 SKU/产品名称、展开完整列表。小屏保留可横向滚动的完整明细表。

## 异常

网络或登录失效时显示错误并可重新读取，不用其他店铺或过期预览数据填充。更新登录状态须在原每日推送工具完成。切换店铺会取消上次读取；服务端再次核对精确店铺、ID、BRL 币种与分页完整性。

看板不调用任何改价、报名、退出活动或发送消息接口，也不启动或恢复调价任务。

## SKU 批次与流畅度

排行在 SKU 后显示批次。在连接设置导入 .xlsx 批次对应表，识别 SKU 与批次（或顺序上架）列。SKU 忽略首尾空格与大小写；空值及 Excel 错误值显示“未匹配”。同一 SKU 有不同有效批次时拒绝导入并保留原映射。批次映射仅保存在本机数据目录，不随安装包或源码上传；更换电脑需重新导入。重新导入仅更新本地批次，不读取 UpSeller 销售数据。

切回看板播放一次轻量入场动效，保留当前搜索与展开状态。使用复用的数字格式器及静态金额，避免逐帧 React 更新；以渐变玻璃质感代替每张卡片的实时背景模糊，侧边栏流光保留。离开调价工作台暂停前端详情/日志轮询，返回后从日志游标继续读取，后台业务任务照常执行。
