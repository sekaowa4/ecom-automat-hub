# 美客多工作台：标签剪裁

打开左侧“标签剪裁”，选择“产品标签”。拖入或选择原始单页PDF，然后点击“开始剪裁”，完成后逐份下载。

- 每文件最大10MB，一批最多20个文件。文件逐个处理，失败会显示原因并继续下一份。
- 每份原PDF生成一个多页PDF，每页一张标签；保持原尺寸，保留文字和条码，不转图片。沿用所提供工具的边框识别及排序规则。
- 仅支持带矩形边框的原始单页PDF；已裁好的多页文件、损坏或加密PDF可能无法处理。无边框会提示，不猜测裁切区域。
- 可点击“停止剪裁”终止当前处理；已完成结果仍可下载。切换工作台功能不清空列表，刷新或关闭页面会清空，请及时保存下载文件。
- 文件仅在本机处理，不需要店铺登录。临时输入输出在处理后清理，不写入调价任务记录。
- “箱唛标签”已开放：上传原始A4横向三列PDF，支持多页及末页不足三张；每张箱唛独立一页，完整保留条码、二维码、箱号及底部信息。详细规则见“箱唛裁切与标签预览.md”。
- 两种标签均提供原文件和剪裁结果预览，支持浏览器翻页、缩放、单独打开及下载。

产品名称升级为“美客多工作台”，原调价工作台、9款皮肤和历史任务保留。左上角使用美客多握手标志，主体线条和底色随皮肤变化。品牌图形来源：https://github.com/pheralb/svgl/blob/main/static/library/mercado-libre.svg ，仅适配主题配色。

程序包内含标签剪裁组件，同事无需安装Python。请分享完整ZIP，勿只复制主程序。
