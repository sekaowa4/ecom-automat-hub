# 调价速度优化（0.5.29）

此版本减少读取过程的重复控制命令、空等待和保存后重复整页跳转，不改变输入表目标价、收益优先、活动选择或多链接处理范围。

- 同一轮读取共用已检查的页面 frame，操作后仍检查验证跳转；明确没有商品分组时不执行展开脚本。
- 页面就绪轮询从 75、125、200 毫秒逐步增加至最多 700 毫秒。页面已就绪便继续，原有总超时仍保留；分组展开点击至少间隔 700 毫秒，避免重复开关。
- “更多促销”脚本已有等待内容稳定的逻辑，结束后直接重新读取，不再额外固定等待 700 毫秒。
- 保存后保留首次 2.5 秒缓冲及独立页面回读。若平台尚未显示目标价，随后两次使用同一新文档进行 250、500 毫秒轮询；仍不一致则恢复整页刷新和较长等待。商品管理独立原价核验仍使用原有路径。
- 同文档复用要求搜索地址、SKU 查询与 loader 均一致；编辑框未关闭则按结果未知处理。独立导航必须等旧文档退出，无新 loader 时显式重新加载，防止误将提交前页面视作回读结果。
- 日志新增逐阶段耗时、CDP 命令次数和整页跳转次数。总核验包含子读取耗时，分析时不能将父子阶段相加。

本机模拟 CDP 基准中，10 个已就绪的无分组 SKU 读取从 100 次命令降到 50 次；两个短暂未就绪状态不再固定等待两次 700 毫秒。该基准用于检查程序开销，不代表真实店铺的总耗时或平台响应速度。

同店铺仍串行执行，验证仍暂停；所有保存前检查点和保存未知先回读规则保留。没有增加保存重试或直接接口改价。真实批次的提速幅度应以新日志比较相同业务场景后确认。

## 0.5.53 网络与页面卡顿重试

日常调价与周末报名将明确的请求超时、连接失败、代理失败、页面下拉或展开未响应标记为网络问题，并持续重试。先处理本轮其他记录；等待间隔依次为30、60、120、240秒，随后最多每5分钟一次，没有次数上限。已完成记录不重做，同店铺仍串行；手动暂停与店铺验证仍会停止后续操作。

每次重试保留原商品、目标价和提交检查点，保存结果未知先回读，禁止直接重放保存。价格限制、身份或报价冲突、审核、人工验证和无法确认是否为存储故障的异常不会进入无限网络重试；其他可重试异常仍最多3次。执行明细可筛选网络问题，并显示具体类别、已尝试次数和下次重试时间。旧批次只有在操作者手动继续时才重新识别明确的网络失败，不会自动启动暂停批次。

## 0.5.57 提速优化与独立测试记录

只在独立源码副本实现和模拟验证，不连接真实店铺，不替换正在执行批次的程序。

- 促销保存后，已确认 SKU 身份的商品按绑定商品 ID 回读，避免每轮重复进入商品管理和变体页面；身份不明、返回不唯一或身份不符时回退完整识别。改原价、折扣原价路径保持原有检查。
- 仍等待首次 2.5 秒，并要求两次独立新文档核验。没有复用旧价格作为成功结果，没有增加保存重放。
- 刚完成核验且编辑框已关闭时，同一店铺、SKU、明确商品 ID 的下一条活动计划可复用当前文档一次；有效期 15 秒。每次仍重新读取页面内容。地址或 loader 变化、编辑框未关闭、超时、断线、范围变化或重试均回退原路径。
- 模拟旧式共享链接的两次核验，整页跳转从 8 次降至 2 次；这只是该场景的程序开销改善，不代表真实批次已提速。当前运行版本不变，部署后需用相同业务场景的阶段日志确认实际效果。

## 0.5.57 合并修复发行（用户指定版本号）

本发行合并独立提速优化、人民币/雷亚尔参考汇率及已参加活动逐项补调修复。GitHub 曾单独备份汇率为 0.5.58；此次按用户指定名称统一发行 0.5.57，不覆盖历史提交。

- 展开的商品分组汇总不再冒充无 SKU 的旧式链接；完整读取子商品后按精确 SKU 和每个商品 ID 拆分，仍保留无法展开及共享目标冲突的待核对。
- 已参加的可编辑平台活动（含双十一）与预约普通活动分别建行、分别记录提交与回读，不把编号 P 一概当成只可退出的补贴。新提案不进入自动拆分。
- 预约活动直接提价遇到旧价格上限时，在已授权提价范围内退出并重报同一活动；已确认的双十一或 Black Friday 只有明确退出权限时才使用同活动重报，普通补贴不使用该例外。重报仍受平台实际价格上限约束，拒绝时明确待核对，不降低表格目标价。
- 双十一编辑框的“每日精选 + 11.11”主活动标记可被准确识别；其他叠加活动和冲突名称仍拒绝。
- 补贴只提供增加折扣、没有目标价输入框时明确报告平台限制，不误报网络超时。明确“保留补贴”的指示优先；其他已授权范围仍按目标活动实报净收比较是否切换补贴，并双回读最终实际售价。
- 原价编辑识别不同样式的运费确认框；若确认框由输入失焦提前触发，先核验商品、SKU、目标和运费，再确认并单次保存主表单，不能把关闭提示框当作保存完成。
- 活动成功表示该行指定活动已核验；是否实际生效仍依回读活动状态及当前售价展示。每个链接、每个活动分开记录，整项缺失不能由其中一项成功代替。

## 0.5.58 稳定未生效价格快速回队

- 保存后仍进行两次独立页面回读。若目标价尚未出现，且两次完整商品、活动、原价和实际售价快照完全相同，则本轮立即以待核对返回，让同店后续 SKU 继续处理；下一次重试依原检查点先回读，不盲目重放保存。
- 状态仍在变化、需要原价核验或折扣原价核验时保留原有等待与独立核验路径。
- 该改动针对保存后价格稳定未刷新的行；不会减少首次商品读取、提价退出/重报流程或页面导航。
