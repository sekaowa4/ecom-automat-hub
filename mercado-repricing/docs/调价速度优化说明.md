# 调价速度优化（0.5.29）

此版本减少读取过程的重复控制命令、空等待和保存后重复整页跳转，不改变输入表目标价、收益优先、活动选择或多链接处理范围。

- 同一轮读取共用已检查的页面 frame，操作后仍检查验证跳转；明确没有商品分组时不执行展开脚本。
- 页面就绪轮询从 75、125、200 毫秒逐步增加至最多 700 毫秒。页面已就绪便继续，原有总超时仍保留；分组展开点击至少间隔 700 毫秒，避免重复开关。
- “更多促销”脚本已有等待内容稳定的逻辑，结束后直接重新读取，不再额外固定等待 700 毫秒。
- 保存后保留首次 2.5 秒缓冲及独立页面回读。若平台尚未显示目标价，随后两次使用同一新文档进行 250、500 毫秒轮询；仍不一致则恢复整页刷新和较长等待。商品管理独立原价核验仍使用原有路径。
- 同文档复用要求搜索地址、SKU 查询与 loader 均一致；编辑框未关闭则按结果未知处理。独立导航必须等旧文档退出，无新 loader 时显式重新加载，防止误将提交前页面视作回读结果。
- 日志新增逐阶段耗时、CDP 命令次数和整页跳转次数。总核验包含子读取耗时，分析时不能将父子阶段相加。

本机模拟 CDP 基准中，10 个已就绪的无分组 SKU 读取从 100 次命令降到 50 次；两个短暂未就绪状态不再固定等待两次 700 毫秒。该基准用于检查程序开销，不代表真实店铺的总耗时或平台响应速度。

同店铺仍串行执行，验证仍暂停；所有保存前检查点和保存未知先回读规则保留。没有增加保存重试或直接接口改价。真实批次的提速幅度应以新日志比较相同业务场景后确认。
