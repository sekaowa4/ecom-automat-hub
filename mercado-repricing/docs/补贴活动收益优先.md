# 补贴活动收益优先

## 0.5.4：实际报名后比较（当前规则）

普通活动先按表格目标实际报名，保留原有补贴；重新读取同商品两活动实际净收。补贴净收更高或相等则保留并注明实际售价与目标差异；普通活动净收更高，且已确认目标普通活动实报、精确商品及两活动净收时，才退出低收益补贴。预约未激活不能冒充目标已生效。

平台上限使普通活动无法报到目标，而现有普通活动实际净收更低时，按用户明确选择保留高收益补贴，并注明未达到目标价。旧式共享多SKU商品只比较已有活动，不为单一SKU统一修改父价。未知提交先回读，不重复报名或退出。净收缺失、区间、矛盾重复行均禁止据此退出。

## 0.5.2：历史试算规则

本次不执行真实店铺价格或退出活动。

新建实际调价批次默认启用收益优先，并将策略保存在批次记录中；旧批次的范围和历史规则不自动升级，需重新上传创建新批次使用本规则。

1. 同一精确商品存在唯一生效平台活动（P-）时，先读取当前净收款额。
2. 找到唯一可报名或可编辑已预约普通活动，打开弹框填入表格目标价，只读取平台净收款额试算，然后取消；绝不确认报名。
3. 两次以上稳定读数且目标金额已刷新才采用；出现额外勾选、未知活动名、金额区间、未刷新旧值、页面变化或验证时，不凭售价估算净收款额。
4. 比较后重新读取商品、活动、原价、活动价和净收款额，全部相同才能继续。
5. 当前补贴净收款额大于或等于目标普通活动时，记录“已保留高收益补贴”，展示两边净收款额、当前售价及表格目标；不计入调价成功，单独汇总。
6. 目标普通活动净收款额更高时，仍须满足原有退出、身份、活动、折扣范围和授权校验才能继续。不得因试算较高就跳过原校验。
7. 净收款额缺失、无法唯一比较、第三种改原价后无法预先获得可靠试算等情况，保留待核对，不退出补贴。

比较口径是同商品、同成本下的平台净收款额，并非完整成本利润。P-管理的秒杀活动也采取保守比较。

页面标签支持中文和葡语。新布局无法精确提取时停止在待核对，不能视为零收益或强制退出。

验收：248项后端、15项前端、15组浏览器模拟场景全部通过；已发布0.5.2并在空闲状态切换本地服务。没有提交真实调价或退出活动；真实补贴商品的试算读取尚未现场验收，未知页面布局会保留待核对。
