# 周末活动报名与验证日志（0.5.26）

## 周末活动报名

侧栏“调价工作台”展开后有“日常调价”和“周末活动报名”。报名页面自动显示本周五至周日的活动日期，例如本周为 2026-10-23 至 2026-10-25，显示名称为 10.23-10.25。日期按北京时间计算；每周一开始识别下一场周末。跨月、跨年同样处理。

运营先在平台创建普通活动，再选择店铺、下载本页模板，填写产品、SKU、报名价格。没有调价动作列，不需要填写或选择活动名称。若目标活动藏在商品的“查看更多促销”中，程序只展开表格 SKU 所属分组中的更多活动后重新读取（展开入口可能位于 SKU 行下方）；只报名日期匹配的唯一普通活动，不代为创建平台活动，也不选择补贴、秒杀或新提案。展开仅显示活动信息，不会报名、退出或编辑其他活动。报名表支持 XLSX 和 UTF-8 CSV。

每个任务创建时保存完整日期，之后恢复执行不会换到下一场。任务记录显示“周末活动报名”和当时的日期，保存上传原表及完整日志。日期跨周发生变化时，需刷新并重新确认；已过期任务不能继续报名。

成功核验要求同一 SKU、商品编号、活动编号、原价和目标活动价一致，且活动为激活或已预约。预约成功也属于报名完成，但不表示当前成交价已经切换。其他活动、原价、广告选项不在本功能的修改范围。

旧式多个 SKU 共用同一父链接价格时，按父链接统一报名：表格必须覆盖该链接全部关联 SKU，且目标报名价一致，才提交一次；缺少关联 SKU 或目标价冲突时保留待核对。后续关联 SKU 行只回读确认已报名结果，不重复提交。找不到 SKU 会跳过；找不到对应日期活动、多场同日期活动、平台价格限制、已报名但目标价格不一致时会说明原因并保留待核对。保存结果未知先回读；仅当两次独立页面读取均确认同一活动仍未报名、原价及其他生效活动保持原状态时，才沿用原商品、活动与目标价格恢复报名。状态变化或无法确认时继续保留待核对。平台价格上下限直接显示具体金额，不自动替换表格价格。

## 页面连接故障与验证的区分

未确认进入验证页时，页面控制通道读取失败属于连接故障：日志记录具体操作节点，当前行保留提交检查点，在行结束后暂停整批，不弹“请先完成店铺验证”。修复连接后继续会重新建立专用工作连接并先回读。只有实际检测到登录或验证页面，才进入验证等待及必要的验证弹窗。

## 验证期间的行为

发现验证页后，当前改价操作停止，界面显示“等待自动验证”。完整日志记录 SKU、操作节点（例如“原价 submit”“活动 submit”）、进入验证、检测到自动填充后单次确认、验证通过、超时或页面控制中断。

验证码、二维码及带参数的验证链接不会写入任务日志。自动填充未完成不点击；无法可靠确定验证状态、自动验证超时或验证期间操作等待中断时，整批转人工暂停。人工继续前不再改价。

验证打断的保存命令不会重放。验证通过后原页面上下文不再直接沿用，先重新读取商品与之前的提交结果，再按已记录检查点决定后续步骤。

任务日志下载使用 UTC 时间（+00:00），北京时间需加 8 小时。界面日志时间按浏览器本地时区显示。

## 给同事升级

先从旧工作台点击“退出程序”，完整解压新版压缩包后启动。不要仅复制 EXE，务必保留 wwwroot、assets 及其他随包文件。启动后查看左下角与 /api/health 均为 0.5.26，必要时 Ctrl+F5 刷新。


## 0.5.31 验证提醒与运费确认

真实验证页出现时立即显示 Windows 等待提醒，自动填充确认期间停止改价；通过后提醒自动关闭并先回读。自动阶段收起提醒不代表验证通过；超时换为人工继续弹窗。普通运费提示兼容单笔金额和旧、新金额对照，仍绑定当前 SKU、商品和目标价，仅确认一次，保存结果仍须回读。
