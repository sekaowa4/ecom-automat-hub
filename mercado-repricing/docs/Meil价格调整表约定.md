# Meil 价格调整表约定

用户于 2026-10-15 指定桌面的 Meil价格调整表.xlsx 为后续发送调价表的格式。内部空白模板为 samples/Meil价格调整表-模板.xlsx，仅保留表头，不保留实际商品或价格数据。

工作表 Sheet1，第一行固定四列表头，顺序如下：

| 列 | 原始表头 | 用途 |
|---|---|---|
| A | 产品 | 产品说明，不用作唯一商品身份 |
| B | sku | 精确 SKU，按文本保留 |
| C | 调价动作 | 可填提价/降价或留空；0.4.7混合模式按店铺实时价与目标自动判断实际方向 |
| D | 折扣价格 | 目标活动售价，不是折扣比例，也不是净收款额 |

后续按此格式接收表格，不要求用户为区分提价降价重命名列或拆成两个工作表。自2026-10-16用户确认整表混合调价，0.4.7新建实际调价任务按实时价格判断升降，表内动作仅作记录；相同价格跳过，活动不明不提交。旧任务保留原降价范围。是否需要改原价取决于平台活动限制；本表没有提供目标基础售价，不能从目标活动价反推并擅自修改原价。

本表不需要店铺、站点列。0.3.0 检查时从紫鸟读取美客多店铺列表，自动按每个支持店铺展开全部源行；站点来自店铺平台信息，不从 SKU 后缀猜测。检查结果显示店铺清单及展开项数，创建任务后范围固定。非美客多配置不纳入；目前不支持的美客多站点明确提示未纳入。搜索明确为空时只跳过该店这一项，存在模糊链接或未加载完的分组时待核对；连接、登录或解析失败不会伪装成 SKU 不存在，而会暂停批次。

0.3.0 已适配四列直接上传，自动识别跨店模式并选择只读查询；下载标准模板返回嵌入程序的四列表头 Excel。调价动作保留到输入、预览、任务和导出；与店铺实时价格方向相反时标待核对，目标价相同则跳过。0.4.0 增加“实际降价”入口，需单独选择并确认范围；只处理已有活动内降价，提价和改原价仍待核对。只读模式继续不改价。
