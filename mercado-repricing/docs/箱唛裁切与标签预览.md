# 箱唛裁切与标签预览（0.5.3）

## 箱唛标签

侧栏“标签剪裁 → 箱唛标签”，上传美客多导出的原始PDF。支持A4横向、每页最多三列的完整箱唛，支持多页和末页不足三张。按原页顺序、每页从左到右输出，每张标签占一页，保留上下完整边框、条形码、二维码、箱号和底部VOLUMES信息，不缩放、不转图片。

裁切范围依据已提供的处理后PDF：三列横坐标22.6801／289.386／555.375／819.927 pt，纵坐标133.877至571.847 pt。必须先通过页面尺寸、完整边框、唯一箱号及VOLUMES校验，不能只按坐标盲裁。缺失边框、重复箱号、加密、已裁切或不同布局会明确报错，不生成不完整文件。

每份最大10MB、最多200页／600张；一次最多选择20份文件，依次处理。失败文件不阻塞后续文件，可停止、继续和逐份下载。组件内置，同事无需安装Python或其他裁切工具。

## 两种标签预览

产品标签和箱唛标签都提供原文件预览及剪裁结果预览。使用浏览器PDF阅读器，可翻页、缩放、单独打开和下载。预览弹窗支持Esc关闭，保留当前皮肤。建议使用Chrome或Edge；若浏览器无法内嵌PDF，点击“单独打开”。打印请选择原始尺寸。

切换标签类型时保留各自列表和结果；刷新或退出网页会清空列表，需要自行下载保存。文件只在本机处理，不需要登录店铺，不创建或恢复调价任务。

## 样本验证

用户样本9页生成27张，与提供成品逐页比较，裁切范围、页面尺寸及次序一致。27页渲染图的最大单通道平均像素差约0.0375（255量程），差异来自PDF坐标舍入。合成测试覆盖多页和末页不足三张。
