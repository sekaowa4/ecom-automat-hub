# E-commerce Automation Hub

电商运营自动化项目集合。

## 项目

- [Mercado Livre Auth Mailer](mercado-livre-auth-mailer/README.md)：在 Windows 上通过紫鸟采集 Mercado Livre 店铺授权码，校验完整批次后发送邮件及企业微信通知。
- [Brazil Stock Sync](brazil-stock-sync/README.md)：通过 UpSeller 接口生成巴西 Stock_Order 更新数据，并支持企业微信在线表格写回与核对。

仓库只存放源码、测试和示例配置；实际邮箱配置、凭据、授权码、浏览器会话、库存表及运行记录保留在本机。
