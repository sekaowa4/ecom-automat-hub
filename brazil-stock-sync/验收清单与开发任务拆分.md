# 巴西库存自动化平台验收清单

## 一、数据抓取验收

- [ ] 点击一次“抓取并预览”可以依次完成 UpSeller、OMS 数据抓取。
- [ ] 已登录时复用登录状态，不重复要求登录。
- [ ] 未登录时明确提示登录哪个系统，不继续执行后续步骤。
- [ ] 导出的文件自动识别，不依赖固定文件名。
- [ ] 下载失败、页面超时、导出按钮变化时能记录明确错误。
- [ ] 每个文件记录来源、下载时间、业务日期和文件大小。

## 二、数据质量验收

- [ ] SKU 去除首尾空格后统一匹配。
- [ ] SKU 大小写差异不会造成重复或漏匹配。
- [ ] 同一 SKU 多行库存可以正确汇总。
- [ ] 同一 SKU 多平台、多店铺销量可以正确分组。
- [ ] 未匹配 SKU 单独列出，不自动猜测。
- [ ] 重复 SKU 单独列出，并显示重复来源。
- [ ] 空库存、空销量和空待开票数量按业务规则处理。
- [ ] `#N/A`、`#VALUE!`、空字符串等错误值不会被写入输入列。
- [ ] 源文件日期不一致时，预览页显示警告。

## 三、计算结果验收

- [ ] 3/7/15/30 天销量分别对应正确周期文件。
- [ ] 加权平均日销继续使用 Stock_Order 原公式。
- [ ] 可售天数继续使用 Stock_Order 原公式。
- [ ] 重点店铺继续由店铺销量公式计算。
- [ ] 国内补货建议和国内补货数量继续由原公式计算。
- [ ] 总库存等汇总公式不被程序覆盖。
- [ ] 采购成本按 SKU 正确关联。

## 四、写入安全验收

- [ ] 写入前自动生成带时间戳的备份。
- [ ] 预览阶段不改目标表。
- [ ] 只有点击“确认更新”后才执行写入。
- [ ] 只写入允许更新的输入列。
- [ ] 公式列写入前后数量一致。
- [ ] 写入中途失败时保留原文件和备份。
- [ ] 写入后重新读取关键区域进行校验。
- [ ] 运行日志记录更新行数、异常数和失败原因。

## 五、页面验收

- [ ] 首页显示厦门众赢未来科技有限公司标识。
- [ ] 同时显示北京时间和巴西时间。
- [ ] 显示当前运行状态：未运行、抓取中、待确认、更新中、完成、失败。
- [ ] 显示上次运行时间和数据日期。
- [ ] 显示成功匹配、未匹配、重复和异常数量。
- [ ] 预览表支持按 SKU、店铺和异常状态筛选。
- [ ] 失败时能看到具体系统和具体步骤。

## 六、第一版不做的功能

- 不自动提交采购订单。
- 不自动修改 OMS 库存。
- 不自动发送企业微信群消息。
- 不自动删除历史导出文件。
- 不根据产品名称猜测 SKU。
- 不覆盖 Stock_Order 原有公式。

## 七、开发任务拆分

### M0：数据引擎验证

输入现有本地导出文件，完成：

1. 文件识别；
2. 表头识别；
3. SKU 标准化；
4. 库存和销量聚合；
5. 店铺名称映射；
6. 异常清单；
7. 预览结果。

M0 不连接网页、不写回 Stock_Order，目的是先证明计算结果正确。

### M1：UpSeller 自动抓取

完成登录态复用、产品销量页面访问、日期筛选、导出和下载文件识别。

### M2：OMS 自动抓取

完成库存清单导出、效期明细导出、文件识别和字段标准化。

### M3：Stock_Order 安全更新

完成备份、输入列更新、公式保护、写后校验和失败恢复。

### M4：桌面应用

完成界面、日志、配置、路径选择、时间显示、异常提示和 `.exe` 打包。

## 八、开发完成判定

只有同时满足以下条件，才算第一版完成：

- 连续 3 次使用不同日期数据运行成功；
- 每次都能生成预览结果；
- 未匹配和重复数据都有明确显示；
- Stock_Order 公式列未被破坏；
- 运行失败时原始文件可恢复；
- 同事在另一台 Windows 电脑上无需安装 Python 即可运行 `.exe`。
