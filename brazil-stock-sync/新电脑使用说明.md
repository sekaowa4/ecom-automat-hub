# 新电脑交接说明

先在原电脑双击 `创建新电脑迁移包.cmd`。把桌面生成的“巴西库存更新自动化平台-新电脑迁移包”文件夹复制到新电脑任意位置。

在新电脑完成以下一次性配置：

1. 安装并登录 Codex，然后双击 `新电脑初始化.cmd`。
2. 粘贴正式 `Stock_Order` 在线表链接、企微群 Webhook，以及 UpSeller Cookie 的 `us_u` 值。
3. 在新电脑重新初始化并授权企业微信文档 MCP；不要复制旧电脑的 `runtime\wecom-cli` 授权文件。
4. 双击 `运行前检查.cmd`。只有全部通过，才可正式运行。

之后在新电脑的 Codex 中打开该文件夹，发送以下指令即可：

> 你给我最新的数据生成stock表再写入在线表，只有成功了再发送群通知

也可以双击 `运行今日库存更新.cmd`。程序会从 UpSeller 接口获取六份最新数据，写入正式在线表；任何步骤失败都不会发送群通知。

## 不要复制的内容

迁移包不会携带 UpSeller Cookie、企业微信 MCP 授权、群 Webhook、下载文件、日志或历史 Stock 表。它们都属于旧电脑的本机数据或敏感凭据。
